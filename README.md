# Bionexus.AI website

Static website for Bionexus.AI, intended for GitHub Pages hosting from the `docs/` directory.

## Local preview

```bash
cd docs
python3 -m http.server 4018
```

Then open `http://localhost:4018/`.

## GitHub Pages

In the repository settings, set GitHub Pages to deploy from the `docs/` folder on the desired branch. The homepage is plain static HTML/CSS/JS, so it does not require a custom build step.

## Launch placeholders

- Partner logos and customer references
- Lead program or flagship use case
- Funding status, if public
- Scientific validation metrics
- Disclosure-approved publication and patent links
- Public contact form, intake link, or company inbox
