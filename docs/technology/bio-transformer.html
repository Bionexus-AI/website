Technology 02

Bio-transformer

Biophysics-based embeddings for amino acid sequences that allow sequence-first models to be conditioned on molecular properties rather than sequence context alone.

Physical properties as model context.

Bio-transformer is designed to bridge symbolic protein sequences and biophysical interpretation. It creates embeddings that encode amino acid properties so downstream models can incorporate charge, structure-relevant features, and other physical signals.

The intended role is modular: condition existing sequence-only models, support sequence, graph, and structure-aware architectures, and provide a stronger foundation for client-specific discovery ecosystems.

Representation

Biophysics-based embeddings

Encode amino acid sequences with physically meaningful features for machine learning workflows.

Integration

Condition existing models
