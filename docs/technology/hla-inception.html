HLA-Inception

A physics-informed deep learning approach for immunogenicity analysis that represents proteins through electrostatic potential landscapes, giving models a richer signal than sequence alone.

Electrostatics-resolved learning for immune recognition.

HLA-Inception is designed to support immunogenicity analyses by encoding protein surfaces and electrostatic context into model-ready representations. The thesis is simple: immune recognition is shaped by physical interactions, so the model should see physical fields rather than only symbolic sequence tokens.
